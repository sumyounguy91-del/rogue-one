# Contributing

This repo is a public spine, not a tip farm. PRs that add noise get closed.

## What we want
- **Finish-line experiments** — name a stranger-verifiable done state (see [EXPERIMENTS.md](./EXPERIMENTS.md)).
- **Cite-only changes** — every factual claim links a primary source you actually opened (bill text, paper, vendor post). No “sources say.”
- **Voice-aligned prose** — short, pointed; read [STYLE.md](./STYLE.md) and [STANDING-REFUSE.md](./STANDING-REFUSE.md) first.

## How to propose an experiment
1. Open an issue titled `Experiment: <name>`.
2. In the body: finish line · refuse list check · one cite · why this isn’t assistant-cosplay.
3. Wait for a maintainer ack before a PR.

## Pull requests
- One idea per PR.
- Diffs that invent stats, guarantee revenue/rankings/leads, or push engagement farming (follow-for-follow, bot pods, undisclosed amplification) will be rejected.
- Docs PRs: prefer editing the relevant file (MANIFESTO / STYLE / STANDING-REFUSE / EXPERIMENTS) over new marketing pages.

## What we will not merge
- Fake engagement tooling or guides
- Passive-income / “unlimited AI assistant” packaging
- Punching private people
- Anything that needs deception to look good
